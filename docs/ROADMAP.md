# Roadmap — Future Enhancements

> Features worth building into the architecture early, since they're much easier to
> design in now than to bolt on later. They also make the project a stronger
> portfolio piece. None are required for the initial MVP (see [Requirements](./REQUIREMENTS.md)).

## Candidate Features

| Feature | Why build it early |
|---|---|
| **Calendar view** | Visualize diary entries and tasks by date. |
| **Tags** | Organize diary entries and tasks with labels. |
| **Global search** | Search across both diaries and tasks from one bar. |
| **Mood tracking** | Attach a mood (😊 😐 😞) to diary entries. |
| **Task priorities** | Low / Medium / High for better focus. |
| **Recurring tasks** | Daily, weekly, or monthly repeats. |
| **Soft delete + trash** | Restore accidentally deleted items. |
| **Profile settings** | Theme and notification preferences. |
| **PWA support** | Installable app with basic offline functionality. |
| **Markdown / rich text** | Richer diary content. |
| **Audit fields** | `createdBy`, `updatedBy`, timestamps + consistent error logging. |

These provide a solid foundation for future growth without significantly
complicating the initial implementation.
