# Meri Zindagi

A secure web app for keeping a **daily diary** and managing **daily tasks** in one
place — simple, responsive, and fast, with enterprise-quality architecture.

Built with Next.js 16 (App Router), TypeScript, shadcn/ui + Tailwind CSS, Prisma +
PostgreSQL, and Auth.js.
